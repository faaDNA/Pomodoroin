# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router) + Tailwind CSS + Spring Boot 3 REST API

## Users

Developer/student yang butuh aplikasi Pomodoro ringan tanpa login untuk sesi kerja/fokus & istirahat di browser.

## Product Purpose

Pomodoroin adalah web Pomodoro timer minimalis, cepat, dan responsif. Membantu pengguna tetap fokus dengan interval kerja (25 min) dan istirahat (5/15 min), notifikasi alarm audio, dan opsi kustomisasi durasi.

## Positioning

Aplikasi Pomodoro zero-friction: tanpa registrasi, tanpa iklan, 100% lokal di browser pengguna dengan backend Spring Boot ringan.

## Operating Context

Penggunaan personal di browser (desktop/laptop/tablet) saat bekerja atau belajar.

## Capabilities and Constraints

- Timer Pomodoro dengan mode Focus, Short Break, Long Break.
- Custom interval tersimpan di `localStorage`.
- Audio alarm saat timer habis.
- Integrasi ke backend Spring Boot (`/api/health`, `/api/config`, `/api/stats`).
- Tanpa database persistensi.

## Brand Commitments

- Nama: **Pomodoroin**
- Karakter: Minimalis, bersih, terfokus, modern.
- Arah visual: kategori-standar (pemilik memilih jalur sederhana "buat belajar"; keputusan aesthetik tidak diinovasi tanpa izin).
